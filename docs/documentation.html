Classes

ClassLabelComment
:ProverbProverbThe surface expression of a proverb: its literal text, language, and image/source domain.
:TacitLessonTacit LessonThe unspoken, language-independent moral a proverb conveys.
:SituationOfUseSituation of UseThe pragmatic context in which a proverb would be deployed.
:SourceDomainSource DomainThe literal imagery/domain a proverb draws on (e.g. birds, fish, sleep, food).
:CrossCulturalEquivalenceCross-Cultural EquivalenceA reified link between two proverbs that share a TacitLesson but diverge (or don't) in imagery. Modeled as a full class so the equivalence itself can carry attributes (type, divergence notes, annotator).
