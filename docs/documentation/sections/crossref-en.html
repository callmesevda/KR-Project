grounded in (Wikidata)op back to ToC or Object Property ToC

IRI: https://raw.githubusercontent.com/callmesevda/KR-Project/main/proto-ontology-structure.ttl#groundedIn

Links a TacitLesson or SourceDomain to its grounding concept in Wikidata (range is external, e.g. wd:Q...). Matches the spreadsheet's 'Tacit Lesson URI' and 'Literal Image URI' columns. No rdfs:range is declared deliberately: the value is a Wikidata entity outside this ontology's own classes, so constraining it to one of our classes would be incorrect. This omission is intentional, not an oversight.
Is defined by
https://raw.githubusercontent.com/callmesevda/KR-Project/main/proto-ontology-structure.ttl
Example
