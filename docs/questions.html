Requirements

Competency questions

Competency questions are the natural-language questions an ontology is designed to be able to answer — the requirements that drove PROTO's modeling decisions (why CrossCulturalEquivalence is reified, why lessons and source domains are separate classes, and so on).

Adopted by the team: these eight questions come from Polikseni Hasanaj's 15 September 2026 analyst review of the equivalence links. Each one is the SPARQL query she ran against the live graph to produce a finding in that review, and the team has adopted them as PROTO's competency questions.

CQ1 — How many equivalence links are there of each type?

Answer (15 Sept 2026): 43 SameLessonDifferentImage, 5 DirectMatch. PartialOverlap and FalseFriend are never assigned by the generation script — the starting point for the whole review.

SPARQL 
PREFIX p: <http://example.org/proto#>
SELECT ?type (COUNT(*) AS ?links)
WHERE { ?e a p:CrossCulturalEquivalence ; p:hasEquivalenceType ?type }
GROUP BY ?type

CQ2 — What are all the equivalence links, with both proverbs' languages, translations and type?

Answer: 48 rows — the full list reviewed pair-by-pair; no link ever joins two proverbs of the same language.

SPARQL 
PREFIX p: <http://example.org/proto#>
SELECT ?pair ?langA ?proverbA ?langB ?proverbB ?type
WHERE {
  ?pair a p:CrossCulturalEquivalence ;
        p:linksProverbA ?a ; p:linksProverbB ?b ; p:hasEquivalenceType ?type .
  ?a p:hasLanguage ?langA ; p:hasTranslation ?proverbA .
  ?b p:hasLanguage ?langB ; p:hasTranslation ?proverbB .
}
ORDER BY ?pair

CQ3 — Which proverb pairs between two given languages are direct matches?

Answer for Italian–Albanian: one row — "Chi cerca, trova" / "Kush kërkon, gjen" (PRV-020 / PRV-029). Swap the two language codes to check any other pair.

SPARQL 
PREFIX p: <http://example.org/proto#>
SELECT ?proverbA ?proverbB
WHERE {
  ?pair p:hasEquivalenceType p:DirectMatch ;
        p:linksProverbA ?a ; p:linksProverbB ?b .
  ?a p:hasLanguage "ita" ; p:hasText ?proverbA .
  ?b p:hasLanguage "alb" ; p:hasText ?proverbB .
}

CQ4 — Which source-domain images recur across more than one language?

Answer: "Seeker/Finder" (Farsi, Italian, Albanian) and "Water" (English, Italian, Albanian) top the list, then several two-language pairs. This is also where tag-wording gaps show up — "Sun" is shared by Italian/Albanian, but "Storm"/"Rain" aren't, which is exactly why the generation script missed a real direct match (CQ1's caveat).

SPARQL 
PREFIX p: <http://example.org/proto#>
SELECT ?domain (GROUP_CONCAT(DISTINCT ?lang; separator=", ") AS ?languages)
       (COUNT(DISTINCT ?lang) AS ?n)
WHERE { ?prov p:hasSourceDomain ?domain ; p:hasLanguage ?lang }
GROUP BY ?domain
HAVING (COUNT(DISTINCT ?lang) > 1)
ORDER BY DESC(?n)

CQ5 — Which proverbs share a source-domain image but teach different lessons? (false-friend candidates)

Answer: 4 pairs — see the analyst review for detail. The generation script can't produce these on its own (it only ever links proverbs that already share a lesson); this query finds them by searching across lessons instead.

SPARQL 
PREFIX p: <http://example.org/proto#>
SELECT ?domain ?a ?lessonA ?b ?lessonB
WHERE {
  ?a p:hasSourceDomain ?domain ; p:hasLesson ?lessonA ; p:hasLanguage ?langA .
  ?b p:hasSourceDomain ?domain ; p:hasLesson ?lessonB ; p:hasLanguage ?langB .
  FILTER (?lessonA != ?lessonB && STR(?a) < STR(?b))
}

CQ6 — Which tacit lessons have no direct match at all among the sampled proverbs?

Answer: "Actions over intentions," "Karma," "Optimism in adversity." (Under the review's proposed reclassification, "Optimism in adversity" would leave this list — see the Italian/Albanian "after the rain, the sun" finding.)

SPARQL 
PREFIX p: <http://example.org/proto#>
SELECT ?lesson
WHERE {
  ?lesson a p:TacitLesson .
  FILTER NOT EXISTS {
    ?e p:hasEquivalenceType p:DirectMatch ; p:linksProverbA ?x .
    ?x p:hasLesson ?lesson
  }
}

CQ7 — How many proverbs did each language contribute to each lesson?

Answer: one proverb per language per lesson, except Albanian (two each in "Actions," "Determination," "Karma") and Farsi (two in "Optimism"). This sampling imbalance is part of why the direct-match count is likely an undercount of what's really out there (see the review's finding 6).

SPARQL 
PREFIX p: <http://example.org/proto#>
SELECT ?lesson ?lang (COUNT(?prov) AS ?proverbs)
WHERE { ?prov p:hasLesson ?l ; p:hasLanguage ?lang . ?l p:hasLabel ?lesson }
GROUP BY ?lesson ?lang
ORDER BY ?lesson ?lang

CQ8 — What is everything linked to a given proverb, together with its situation of use?

Answer for PRV-032 ("Uji i qetë të mbyt" / "Quiet water drowns you"): linked to the English, Farsi and Italian "quiet water" proverbs — and their situations of use show they don't all mean the same thing by it (English is admiring, the others warn). Swap in any proverb ID.

SPARQL 
PREFIX p: <http://example.org/proto#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
SELECT ?other ?lang ?proverb ?type ?situation
WHERE {
  { ?e p:linksProverbA p:PRV-032 ; p:linksProverbB ?other }
  UNION
  { ?e p:linksProverbB p:PRV-032 ; p:linksProverbA ?other }
  ?e p:hasEquivalenceType ?type .
  ?other p:hasLanguage ?lang ; p:hasTranslation ?proverb ; p:usedIn ?s .
  ?s rdfs:label ?situation .
}

All eight run live against the TriplyDB SPARQL endpoint. A few more illustrative (but less load-bearing) queries are on the database page.
