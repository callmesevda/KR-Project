Requirements

Competency questions and evaluation

Competency questions are the natural-language questions an ontology is designed to be able to answer — the requirements that drove PROTO's modeling decisions (why CrossCulturalEquivalence is reified, why lessons and source domains are separate classes, and so on). Below them are the data checks that complement the OWL reasoner, and the evaluation of PROTO on real texts.

Adopted by the team: these eight questions come from Polyxeni Chasanai's 15 September 2026 analyst review of the equivalence links. Each one is the SPARQL query she ran against the graph to produce a finding in that review, and the team has adopted them as PROTO's competency questions. In v1.1 the queries use the new GitHub IRIs (proto: for the schema, kg: for the individuals) and the ISO language codes it and sq. The answers are the same as before.

CQ1 — How many equivalence links are there of each type?

Answer: 43 SameLessonDifferentImage, 5 DirectMatch. PartialOverlap and FalseFriend are never assigned by the generation script — the starting point for the whole review.

SPARQL 
PREFIX proto: <https://raw.githubusercontent.com/callmesevda/KR-Project/main/proto-ontology-structure.ttl#>
SELECT ?type (COUNT(*) AS ?links)
WHERE { ?e a proto:CrossCulturalEquivalence ; proto:hasEquivalenceType ?type }
GROUP BY ?type
ORDER BY DESC(?links)

CQ2 — What are all the equivalence links, with both proverbs' languages, translations and type?

Answer: 48 rows — the full list reviewed pair-by-pair; no link ever joins two proverbs of the same language.

SPARQL 
PREFIX proto: <https://raw.githubusercontent.com/callmesevda/KR-Project/main/proto-ontology-structure.ttl#>
SELECT ?pair ?langA ?proverbA ?langB ?proverbB ?type
WHERE {
  ?pair a proto:CrossCulturalEquivalence ;
        proto:linksProverbA ?a ; proto:linksProverbB ?b ; proto:hasEquivalenceType ?type .
  ?a proto:hasLanguage ?langA ; proto:hasTranslation ?proverbA .
  ?b proto:hasLanguage ?langB ; proto:hasTranslation ?proverbB .
}
ORDER BY ?pair

CQ3 — Which proverb pairs between two given languages are direct matches?

Answer for Italian–Albanian: one row — "Chi cerca, trova" / "Kush kërkon, gjen" (PRV-020 / PRV-029). Swap the two language codes (en, fa, it, sq) to check any other pair.

SPARQL 
PREFIX proto: <https://raw.githubusercontent.com/callmesevda/KR-Project/main/proto-ontology-structure.ttl#>
SELECT ?proverbA ?proverbB
WHERE {
  ?pair proto:hasEquivalenceType proto:DirectMatch ;
        proto:linksProverbA ?a ; proto:linksProverbB ?b .
  ?a proto:hasLanguage "it" ; proto:hasText ?proverbA .
  ?b proto:hasLanguage "sq" ; proto:hasText ?proverbB .
}

CQ4 — Which source-domain images recur across more than one language?

Answer: "Seeker/Finder" (Farsi, Italian, Albanian) and "Water" (English, Italian, Albanian) top the list, then several two-language pairs. This is also where tag-wording gaps show up — "Sun" is shared by Italian/Albanian, but "Storm"/"Rain" aren't, which is exactly why the generation script missed a real direct match (CQ1's caveat).

SPARQL 
PREFIX proto: <https://raw.githubusercontent.com/callmesevda/KR-Project/main/proto-ontology-structure.ttl#>
PREFIX rdfs:  <http://www.w3.org/2000/01/rdf-schema#>
SELECT ?domain (GROUP_CONCAT(DISTINCT ?lang; separator=", ") AS ?languages)
       (COUNT(DISTINCT ?lang) AS ?n)
WHERE { ?prov proto:hasSourceDomain ?d ; proto:hasLanguage ?lang . ?d rdfs:label ?domain }
GROUP BY ?domain
HAVING (COUNT(DISTINCT ?lang) > 1)
ORDER BY DESC(?n) ?domain

CQ5 — Which proverbs share a source-domain image but teach different lessons? (false-friend candidates)

Answer: 4 pairs — see the analyst review for detail. The generation script can't produce these on its own (it only ever links proverbs that already share a lesson); this query finds them by searching across lessons instead.

SPARQL 
PREFIX proto: <https://raw.githubusercontent.com/callmesevda/KR-Project/main/proto-ontology-structure.ttl#>
PREFIX rdfs:  <http://www.w3.org/2000/01/rdf-schema#>
SELECT ?domain ?a ?lessonA ?b ?lessonB
WHERE {
  ?a proto:hasSourceDomain ?d ; proto:hasLesson ?lessonA .
  ?b proto:hasSourceDomain ?d ; proto:hasLesson ?lessonB .
  ?d rdfs:label ?domain .
  FILTER (?lessonA != ?lessonB && STR(?a) < STR(?b))
}
ORDER BY ?domain

CQ6 — Which tacit lessons have no direct match at all among the sampled proverbs?

Answer: "Actions over intentions," "Karma," "Optimism in adversity." (Under the review's proposed reclassification, "Optimism in adversity" would leave this list — see the Italian/Albanian "after the rain, the sun" finding.)

SPARQL 
PREFIX proto: <https://raw.githubusercontent.com/callmesevda/KR-Project/main/proto-ontology-structure.ttl#>
SELECT ?lesson
WHERE {
  ?l a proto:TacitLesson ; proto:hasLabel ?lesson .
  FILTER NOT EXISTS {
    ?e proto:hasEquivalenceType proto:DirectMatch ; proto:linksProverbA ?x .
    ?x proto:hasLesson ?l
  }
}
ORDER BY ?lesson

CQ7 — How many proverbs did each language contribute to each lesson?

Answer: one proverb per language per lesson, except Albanian (two each in "Actions," "Determination," "Karma") and Farsi (two in "Optimism"). This sampling imbalance is part of why the direct-match count is likely an undercount of what's really out there (see the review's finding 6).

SPARQL 
PREFIX proto: <https://raw.githubusercontent.com/callmesevda/KR-Project/main/proto-ontology-structure.ttl#>
SELECT ?lesson ?lang (COUNT(?prov) AS ?proverbs)
WHERE { ?prov a proto:Proverb ; proto:hasLesson ?l ; proto:hasLanguage ?lang . ?l proto:hasLabel ?lesson }
GROUP BY ?lesson ?lang
ORDER BY ?lesson ?lang

CQ8 — What is everything linked to a given proverb, together with its situation of use?

Answer for PRV-032 ("Uji i qetë të mbyt" / "Quiet water drowns you"): linked to the English, Farsi and Italian "quiet water" proverbs — and their situations of use show they don't all mean the same thing by it (English is admiring, the others warn). Swap in any proverb ID.

SPARQL 
PREFIX proto: <https://raw.githubusercontent.com/callmesevda/KR-Project/main/proto-ontology-structure.ttl#>
PREFIX kg:    <https://raw.githubusercontent.com/callmesevda/KR-Project/main/proto_data.ttl#>
PREFIX rdfs:  <http://www.w3.org/2000/01/rdf-schema#>
SELECT ?other ?lang ?proverb ?type ?situation
WHERE {
  { ?e proto:linksProverbA kg:PRV-032 ; proto:linksProverbB ?other }
  UNION
  { ?e proto:linksProverbB kg:PRV-032 ; proto:linksProverbA ?other }
  ?e proto:hasEquivalenceType ?type .
  ?other proto:hasLanguage ?lang ; proto:hasTranslation ?proverb ; proto:usedIn ?s .
  ?s rdfs:label ?situation .
}
ORDER BY ?other

All eight were re-run on the v1.1 files with test/run_queries.py (output in query_results.md). They can also be pasted into the TriplyDB SPARQL endpoint. A few more illustrative (but less load-bearing) queries are on the database page.

Validation

Data checks the reasoner cannot do

OWL reasons under the open-world assumption: it reports a wrong value (a proverb that is also typed as a lesson, a link with two equivalence types) but not a missing one. These SPARQL checks cover that gap. On the v1.1 graph all of them return no rows, and an OWL 2 RL reasoner finds no inconsistency.

CheckQuestionResult
V1Which proverbs have no tacit lesson?none
V2Which equivalence links join two proverbs of the same language?none
V3Which links that are not FalseFriend join proverbs with different lessons?none
V4Which proverb occurrences in the text graph have no stance or no target?none

Evaluation · Polyxeni Chasanai · October 2026

Testing PROTO on real texts

To test the ontology, we used it as a lens on real texts where people use proverbs from our corpus: news, blogs, a forum thread, a social media post and opinion pieces. Every use was annotated by hand and turned into a small knowledge graph that imports the PROTO schema and the main graph. PROTO is good at saying which proverb is used and which lesson it carries. It has no way to say who the proverb is aimed at or what attitude the speaker takes, and those are the things that show bias, so the test also produced a proposed extension module.

What the ontology captured

  • All 11 occurrences fit the existing model: each becomes a new SituationOfUse attached to its proverb through usedIn, and each maps onto one of the six tacit lessons. No new lesson was needed.
  • One proverb was missing from the corpus: "a few bad apples". It was added as PRV-101 under Group vulnerability, with a new source domain Apple, and linked to the Albanian PRV-031 ("one mangy sheep spoils the whole flock") as SameLessonDifferentImage, with annotatedBy filled in.
  • Two texts back up the analyst review. In T5, forum users disagree on whether "Still waters run deep" is praise or a warning, so the English proverb overlaps in use with the Albanian "Uji i qetë të mbyt". T9 confirms that the Persian "Aunt Bear" proverb is about a foolish friend whose help does harm.

The extension (proto-text-extension.ttl) is a separate module and a proposal: it does not change the main schema. It follows the same modelling rules as PROTO v1.1 (disjoint classes, closed value lists, functional properties).

Bias: what the queries show

  • The same phrase can defend or accuse. "One bad apple" used to mean that one bad member spoils the whole group. In T1, officials say "a few bad apples" to argue the opposite: the police as a whole are fine. T2 criticises exactly this use. In the graph this is one proverb with two stances aimed at the same group.
  • A warning can be turned into a promise. In T6 the journalist uses sow/reap as a warning to people in power, while the Prime Minister uses the same image to promise that today's reforms will pay off.
  • Proverbs let people blame without naming anyone. T3 makes "employees" the weakest link in order to sell a security product. T7 warns about "whoever sows wind" in the migration debate and leaves the reader to work out who that is.
  • Karma proverbs show up in politics. Four of the five Karma occurrences are warnings to politicians, governments or citizens.

Can the proverbs be found automatically?

MethodFoundCorrectRecallMissed
Exact text from the graph (hasText)660.67"a few bad apples" (T1, T2), the split sow/reap form in T6
Key words991.00none

Both were compared with the hand annotation (9 text/proverb pairs) plus two decoy sentences, and neither produced a false positive. People rarely quote a proverb exactly: they shorten it, inflect it or split it across a sentence. The key-word result is too optimistic, because the key words were written after reading these texts. Neither method can tell who the proverb is aimed at or with what attitude.

Limitations

  • Nine texts are enough to test the model, not to say how often a proverb is used.
  • The annotation was done by one person, and the stance labels are a judgement call.
  • The Persian text (T9) and the Italian texts (T7, T8) still need a check by native speakers.
